# Van ChatGPT

Zet hier wat ChatGPT (of een designer) maakt: SVG's, afbeeldingen, kleurcodes of notities.
Geef elk bestand een datum en een korte naam, bijvoorbeeld `2026-10-27-logo-handen.svg`.

Claude kijkt in deze map, bouwt wat goed is in de app in, en zet het daarna op GitHub.
Wat is ingebouwd, verhuist naar `design/logo/` of de app zelf; wat is afgevallen naar `design/van-chatgpt/archief/`.
